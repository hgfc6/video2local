# Video2Local

把网页视频下载到本地的 Python 桌面工具。当前第一版聚焦抖音，支持两类入口：

- 单链接解析：粘贴分享文案或短链，解析单个视频的多个清晰度版本，再手动选择下载
- 页面批量同步：在程序启动的专用 Chrome 里打开收藏页或作者作品页，按当前规则串行下载前 N 个或全部视频

项目结构按“平台适配”“解析/下载”“归档命名”“桌面 UI”拆开，后续可以继续扩展到哔哩哔哩、快手、YouTube 等平台，以及更多内容源页面。

## 当前能力

- 当前正式支持平台：`抖音`
- 当前支持的页面类型：
  - `收藏页`
  - `作者作品页`
- 单链接解析默认启用 `kukutool` 解析链路，优先拿更高质量版本；解析失败时会回退到站内链路
- 批量同步按串行方式处理，避免高并发导致接口或第三方解析服务限流
- 支持选择输出目录
- 支持只下载当前页面前 `N` 个视频
- 支持两种落盘方式：
  - 按 `平台/作者` 分目录
  - 直接落到所选目录，不再分子目录
- 支持清晰度策略：
  - `最高可用`
  - `优先超高清`
  - `优先1080p`
- 支持同步前预览和单链接解析共用一张结果表
- 支持整页纵向滚动，窗口高度不够时可以直接向下滚动

## 界面结构

- `下载设置`
  - 选择输出目录
  - 选择是否平铺输出
  - 设置批量同步前 N 个视频
  - 设置清晰度策略
  - 设置失败重试次数
- `批量同步`
  - 启动 Chrome
  - 检查当前页面
  - 下载首个样本
  - 同步前预览
  - 开始同步
  - 停止同步
  - 打开下载目录
  - 查看最近摘要
- `单链接解析`
  - 粘贴抖音分享文案或分享链接
  - 解析分享链接
  - 勾选并下载所选版本
- `结果预览`
  - 整个界面只有这一张公共表格
  - 点“同步前预览”时显示批量预览结果
  - 点“解析分享链接”时显示单链接清晰度列表
- `运行状态`
  - 当前状态
  - 解析来源
  - 当前详情
  - 本次摘要

## 使用方式

### 1. 单链接解析

这个模式不依赖抖音登录，适合单个视频。

支持输入：

- 纯短链接
- 标准抖音视频链接
- 从抖音“分享 -> 复制链接”得到的整段分享文案

例如：

```text
9.76 复制打开抖音，看看【香菜严选的作品】 https://v.douyin.com/5MF6Y_tP8nk/ 08/05 X@Z.Mj :5pm wse:/
```

使用步骤：

1. 启动程序
2. 粘贴分享文案或链接
3. 点击 `解析分享链接`
4. 在公共结果表里查看清晰度、编码、码率、大小、推荐标记
5. 勾选一个版本
6. 点击 `下载所选版本`

### 2. 批量同步

这个模式依赖专用 Chrome 登录态，适合收藏页和作者作品页。

推荐顺序：

1. 点击 `启动 Chrome`
2. 在专用 Chrome 中登录抖音
3. 打开收藏页或作者作品页
4. 点击 `检查当前页面`
5. 点击 `下载首个样本` 验证链路
6. 需要先确认内容时，点击 `同步前预览`
7. 点击 `开始同步`
8. 需要停止时，点击 `停止同步`

批量同步特性：

- 页面会边读取边解析，按串行方式下载，不会先全部解析完再统一下载
- 如果设置了“前 N 个视频”，只处理当前页面采集到的前 N 个候选项
- 当前页面未发现可下载视频时会直接报错，不会静默继续

## 文件命名与输出规则

默认命名规则：

```text
标题-视频ID.mp4
标题-视频ID-清晰度.mp4
```

示例：

```text
山欲摧城-7651428709099242127.mp4
分享视频-7651428709099242127-720p.mp4
```

命名细节：

- `#` 会替换成中文逗号 `，`
- 开头多余的 `，` 会去掉
- 文件名分隔符统一使用 `-`
- 非法 Windows 文件名字符会自动清理

输出目录规则：

- 默认：

```text
downloads/<platform>/<author>/<filename>
```

- 选择“直接下载到所选目录，不再分平台/作者子目录”后：

```text
<你选择的目录>/<filename>
```

样本下载固定保存到：

```text
<输出目录>/_smoke_test/
```

## 项目目录

- `downloads/`：默认下载输出目录
- `.video2local/chrome-profile/`：专用 Chrome 配置目录
- `.video2local/yt-dlp-cookies.txt`：导出的 cookies 文件
- `src/video2local/`：主程序代码
- `tests/`：自动化测试

## 已知边界

- 当前只支持抖音
- 当前批量同步只支持收藏页和作者作品页
- 不接管你平时正在使用的 Chrome，而是使用程序自己的专用 Chrome
- 不做自动登录
- 单链接解析和批量同步都以“当前可获取到的最佳版本”为目标，不承诺一定等于平台理论原画

## 开发环境

1. `python -m venv .venv`
2. `.venv\Scripts\activate`
3. `python -m pip install -e .[dev]`
4. `python -m playwright install chromium`

## 启动应用

如果已经按可编辑模式安装：

```powershell
python -m video2local.main
```

如果直接按当前项目目录运行：

```powershell
.\.venv\Scripts\python.exe -m video2local.main
```

## 运行测试

```powershell
python -m pytest -v
```
